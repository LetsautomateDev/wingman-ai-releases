## Instalacja i aktualizacje

Na Windows uruchom pobrany plik EXE. Na Macu otwórz DMG i przenieś aplikację do Applications. Preview nie ma certyfikatu wydawcy Windows ani notaryzacji Apple, dlatego system może wyświetlić ostrzeżenie lub wymagać ręcznego zatwierdzenia aplikacji.

Od wersji 0.3.1 aplikacja sprawdza nowe wersje automatycznie, jeśli ta opcja jest włączona w ustawieniach. Można też sprawdzić je w **Ustawienia → Aktualizacje**. Instalacja wymaga potwierdzenia. Pakiety aktualizacji są weryfikowane podpisem Tauri.

## Status Preview

To wydanie testowe. Migracja licencji ze starej aplikacji jest jeszcze przed nami; do aktywacji potrzebna jest licencja z nowej bazy. Dotychczasowa baza pozostaje bez zmian.

Kompilacja dla obu architektur Maca nie zastępuje testów dźwięku, uprawnień i Keychain na fizycznym komputerze. Aktualizację Windows z zainstalowanej wersji 0.3.1 do 0.3.2 przez aplikację potwierdzono 19 października 2026. Test aktualizatora na Macu i końcowe porównanie interfejsu 1:1 pozostają do odbioru.
